# Feature Spec: Phase 1 — データ読み込みと基本構造確認

## 1. 目的

CSV ファイルを受け取り、データの基本構造（行数・列数・型・欠損数・先頭行）を標準出力に表示する。
このフェーズの完了をもって「ツールが動く最小単位」とし、以降のフェーズの基盤とする。

---

## 2. 入力ファイルの前提

| 項目 | 仕様 |
|------|------|
| ファイル形式 | CSV（`.csv`）のみ |
| 文字コード | UTF-8 |
| 区切り文字 | カンマ（`,`）|
| ヘッダー行 | 1行目に列名あり |
| 対象外 | Excel、TSV、JSON など（Phase 1 では扱わない） |

---

## 3. サンプルファイル定義: `sample_kpi.csv`

### 最小カラム定義

| カラム名 | 型 | フォーマット | 説明 |
|---------|-----|------------|------|
| `month` | 文字列 | `YYYY-MM` | 対象年月（例: `2024-01`） |
| `department` | 文字列 | 任意 | 部署名（例: `営業部`） |
| `kpi_name` | 文字列 | 任意 | KPI名（例: `売上高`） |
| `kpi_value` | 数値 | 整数または小数 | 実績値 |
| `target_value` | 数値 | 整数または小数 | 目標値 |
| `updated_at` | 文字列 | `YYYY-MM-DD` | データ更新日（例: `2024-01-31`） |

### サンプルデータイメージ

```
month,department,kpi_name,kpi_value,target_value,updated_at
2024-01,営業部,売上高,1200000,1000000,2024-01-31
2024-01,営業部,成約件数,42,50,2024-01-31
2024-02,営業部,売上高,950000,1000000,2024-02-29
```

---

## 4. 出力内容

ファイル読み込みに成功した場合、以下を標準出力に表示する。

| 項目 | 説明 | 表示例 |
|------|------|--------|
| 行数 | ヘッダーを除いたデータ行数 | `行数: 42` |
| 列数 | カラムの総数 | `列数: 6` |
| 列名一覧 | すべての列名をリスト表示 | `列名: month, department, kpi_name, ...` |
| 各列のデータ型 | pandas が推定した dtype | `month: object, kpi_value: float64, ...` |
| 各列の欠損数 | 列ごとの NaN 件数（絶対数） | `kpi_value の欠損: 3` |
| 先頭 5 行のプレビュー | DataFrame の先頭 5 行 | テーブル形式で表示 |

> 欠損率の判定・閾値評価はこのフェーズでは行わない（Phase 2 以降）。

---

## 5. エラー時の挙動

| エラー種別 | 条件 | 期待する動作 |
|-----------|------|------------|
| ファイルが存在しない | 指定パスにファイルなし | `エラー: ファイルが見つかりません: <パス>` を出力して終了 |
| 拡張子が CSV でない | `.xlsx` `.json` 等が渡された | `エラー: CSV ファイルを指定してください` を出力して終了 |
| ファイルが空 | ヘッダーのみ、または 0 バイト | `エラー: データ行がありません` を出力して終了 |
| 文字コードエラー | UTF-8 以外のエンコーディング | `エラー: ファイルの文字コードを確認してください（UTF-8 を想定）` を出力して終了 |

- いずれのエラーも、スタックトレースではなく **人が読めるメッセージ** を出力する。
- エラー時は後続処理を行わず即時終了する。

---

## 6. 成功条件

以下をすべて満たすとき、Phase 1 は完了とみなす。

- [ ] `sample_kpi.csv` を渡すと行数・列数・列名・型・欠損数・プレビューが出力される
- [ ] 存在しないファイルを渡すと適切なエラーメッセージが出力される
- [ ] 空の CSV を渡すと適切なエラーメッセージが出力される
- [ ] 出力内容が人間にとって読みやすい形式になっている

---

## 7. Phase 1 ではやらないこと

以下は意図的に対象外とする。後続フェーズで扱う。

| 項目 | 対応フェーズ |
|------|------------|
| 欠損率の閾値判定（20% 以上か否か） | Phase 2 |
| データ型の不整合・重複行の検出 | Phase 2 |
| 前月比の算出・変化率フラグ | Phase 3 |
| Markdown レポートの生成 | Phase 4 |
| Power BI 改善コメントの出力 | Phase 4 |
| CLI 引数・オプション対応 | Phase 5 |
| Excel (.xlsx) 読み込み | Phase 5（任意拡張） |
