# Mission

kpi-diagnosis-tool は、KPIデータの品質問題を自動検出し、Power BI 改善に向けたコメントを生成するローカルツールです。

## 目的

ビジネスアナリストやデータ担当者が手動で行っているKPIデータの点検作業（欠損確認・異常値チェック・前月比確認）を自動化し、Power BI ダッシュボード改善のための示唆を Markdown レポートとして出力する。

## 対象ユーザー

- KPIレポートを管理するビジネスアナリスト
- Power BI ダッシュボードを保守するデータ担当者
- データ品質チェックを定期的に実施するチーム

## 解決する問題

| 問題 | ツールの対応 |
|------|------------|
| 欠損値の見落とし | 列ごとの欠損率を自動集計 |
| データ型不整合の見落とし | 数値列への文字列混在などを検出 |
| 重複行の見落とし | 完全重複・キー重複を検出 |
| 前月比の手動確認 | 月次カラムを自動比較し変化率を算出 |
| 改善コメントの作成に時間がかかる | 検出結果からMarkdownコメントを自動生成 |

## 成果物

- ローカルで実行できる CLI または Jupyter Notebook
- 入力: CSV ファイル（MVP）
- 出力: Markdown 形式の診断レポート（Power BI 改善コメント含む）

## スコープ外（現時点）

- Web UI
- データベース連携
- Power BI への直接書き込み
- リアルタイム監視
